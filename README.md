# 🌴 정글 점프 탐험대

나뭇가지를 밟고 뛰어다니며 정글 열매를 모으고, 보물상자 속 빛나는 글자를 모아
**'강원특수교육원 강릉분원'**을 완성하는 횡스크롤 게임입니다.
설치 없이 브라우저에서 바로 실행되며 PC와 모바일(터치) 모두 지원합니다.

## 그림
- 기본 탐험가 캐릭터(달리기·점프 모습)와 스테이지 1~4 배경 그림이 index.html 안에 내장되어 있어요
- 발판은 배경 그림에 맞춰 이끼 낀 돌판, 떠 있는 돌섬, 통나무(밟으면 부서짐)로 그려져요

## 게임 방법
- 이동: ← → 또는 A / D
- 점프: 스페이스, ↑ 또는 W (공중에서 한 번 더 누르면 2단 점프, 짧게 누르면 낮은 점프)
- 글라이딩: 떨어질 때 점프를 계속 누르고 있기
- 일시정지: P 또는 Esc
- 모바일·태블릿: 게임이 화면 전체에 나와요. 화면 왼쪽을 누르면 그 자리에 조이스틱이 생기고, 밀어서 이동해요 (조금 밀면 천천히, 끝까지 밀면 빠르게)
- 모바일·태블릿: 화면 오른쪽을 탭하면 점프, 두 번 탭하면 2단 점프, 꾹 누르면 글라이딩
- 가로 화면을 권장하며, 홈 화면에 추가하면 앱처럼 전체 화면으로 실행돼요

## 규칙
- 보물상자를 열면 '강 원 특 수 교 육 원 강 릉 분 원' 중 한 글자가 랜덤으로 나와요 (가끔은 물약)
- 11글자를 모두 모아 '강원특수교육원 강릉분원'이 완성되면 엔딩, 생명이 다 떨어지면 종료
- 생명 5개로 시작 (최대 8개)
- 생명 얻기: 하트, 보물상자의 생명 상자, 한 판에 코인 100개마다, 고릴라 추격전 도망 성공, 비밀 동굴과 보스전의 하트
- 열매: 바나나 10, 체리 15, 망고 20, 용과 40 — 끊기지 않게 먹으면 콤보 (5콤보 ×2, 10콤보 ×3)
- 피해야 할 것: 해골 독열매, 매달린 독거미, 늪 물, 금 간 통나무(밟으면 곧 부서짐)
- 독거미는 위에서 밟으면 물리칠 수 있어요
- 날아오는 앵무새에 닿으면 몇 초간 타고 날아가요 (점프하면 내림)
- 화면 오른쪽 끝 화살표가 다음 보물상자 방향을 알려줘요

## 탐험가 기술 · 수집
- 황금 열매: 10초 동안 커지고, 장애물을 부수고, 열매와 코인을 끌어당겨요
- 코인을 모아 옷장에서 캐릭터(탐험가·원숭이·아기 호랑이·잠수복·우주복·황금 탐험가·내 그림), 점프 잔상(별빛·발자국·하트·나뭇잎·무지개), 파트너(파랑새·꼬마 요정·아기 부엉이)를 고를 수 있어요
- 파트너는 보너스 코인 위치를 알려주고, 물에 빠지기 직전 한 번 구해줘요

## 스릴 · 장치
- 고릴라 추격전: 900m부터 1300m마다 분노한 고릴라가 쫓아와요. 화면이 저절로 흘러가니 250m 동안 뒤처지지 말고 달려요 (따돌리면 코인 +20)
- 점프 버섯: 밟으면 일반 점프의 약 3배 높이로 튕겨 올라 하늘의 코인을 모을 수 있어요
- 줄타기 덩굴: 매달린 뒤 앞으로 크게 흔들릴 때 점프하면 대각선 위로 멀리 날아가요
- 도레미 코인: 코인을 연달아 먹으면 도-레-미-파-솔-라-시-도로 음이 올라가고, 8개째마다 폭죽과 보너스 점수
- 비밀 동굴 포탈: 드물게 나오는 무지개 포탈에 들어가면 10초 동안 코인과 열매가 쏟아지는 보너스 동굴로 가요
- 소나기: 비가 오면 발판이 미끄러워 잘 멈추지 않아요 (화산 지대 제외)

## 물약 (10초)
체공(천천히 떨어짐) · 빛(몸이 빛나 어둠을 밝힘) · 요정(요정이 따라다님) · 자석(열매가 끌려옴) · 거인(커지고 한 번 막아줌) · 느림보(느려짐) · 혼란(좌우 반대)

## 스테이지 (8개)
- 400m마다 스테이지가 바뀌어요 (8 다음엔 다시 1). 한 번 가 본 스테이지는 '스테이지 선택'에서 바로 시작할 수 있어요
  1 폭포 정글 · 2 나무 위 마을 · 3 고대 유적 · 4 화산 지대(용암) · 5 안개 늪지(낮에도 반딧불이) · 6 눈 덮인 고원(미끄러운 눈 발판) · 7 수정 동굴(어둡고 수정이 빛남) · 8 황금 사원(코인이 많음)
- 달릴수록 낮 → 노을 → 밤 → 새벽

## 교실에서 쓰기
- **학생별 프로필**: 시작 화면 맨 위 이름(🐵 탐험가 ▾)을 눌러 '새 친구'를 만들어요. 코인·도감·활력·기록이 학생마다 따로 저장돼요 (프로필이 2명 이상이면 켤 때 '누가 할 차례예요?'가 먼저 나와요)
- **선생님 화면** (시작 화면 👩‍🏫, 처음엔 비밀번호 4자리를 만들어요)
  - 학생별 오늘·전체 이용 시간, 플레이 수, 완성 수, 최고 거리, 안전 카드, 학습 기록, 자주 생명을 잃는 곳
  - 학생마다 '쉬운 설정'(한손·도움·그림) 켜고 끄기, 이름 바꾸기, 삭제, 오늘 시간 +15분
  - 쉬는 시간 알림(기본 20분), 하루 이용 시간 제한
  - 💾 기록 백업 내보내기 / 📂 불러오기 (기기를 바꾸거나 브라우저 기록을 지우기 전에 꼭 백업해요)
  - 🔧 기기 점검: 화면·전체 화면·저장·그림 파일·읽어주기 음성·소리·부드러움을 한 번에 확인
- **💎 내 보물 안내**: 코인·과일·재료·활력·아이템·보너스 생명·배지가 어디서 생기고 어디에 쓰이는지 한 화면에 정리 (로비에 처음 들어가면 한 번 보여줘요)

## 더 쉽게 하기 (선택 · 설정 또는 선생님 화면에서 학생마다)
- ✋ 한 손 모드: 저절로 달리고, 화면 아무 곳이나 탭하면 점프 (로비에서는 방 바로가기 버튼)
- 🤝 자동 난이도 조절: 1분 안에 두 번 생명을 잃으면 발판 사이가 좁아지고 위험한 것이 줄어요 (최대 3단계, 90초 잘하면 한 단계씩 원래대로 · 2인 대결·오늘의 도전 제외)
- 🖼️ 그림·소리 안내: 알림·스테이지 이름·연습 안내·문 이름을 소리로 읽어주고, 위험한 것 위에 ⚠️, 로비에 방 바로가기 버튼

## 로비와 체험실
- 시작 화면에서 '로비로 입장'을 누르면 **강릉분원 섬 마을**이 나와요. 들어올 때마다 8가지 장면 중 하나가 무작위로 골라져요 (`assets/lobby/`)
  - 🌸 봄날(나비·꽃잎) · 🌸 벚꽃잎 날리는 날(꽃잎 바람, 호수에 꽃잎 파문) · ☀️ 여름 물놀이 날(해변에서 헤엄치는 아이들·튜브·비치볼, 호수를 도는 보트) · 🌧️ 비 오는 날(빗줄기·빗방울 파문·물 튀김·천둥 번쩍)
  - 🍁 가을날(떨어지는 단풍잎) · 🍂 바람 부는 날(날리는 낙엽·바람 결, 배가 바람 따라 밀려가며 기울어짐) · ⛄ 겨울 스케이트 날(얼음 호수에서 스케이트 타는 아이들·굴뚝 연기, 주인공도 얼음 위를 걸을 수 있어요) · ❄️ 눈 오는 날(함박눈·안개)
  - 제목 아래 날씨 칩(예: '🍂 바람 부는 날 🔄')을 누르면 다른 장면으로 바뀌어요
  - 간판·버튼·정보판·오늘의 탐험 카드는 모두 코드로 새로 그려요 (그림 속 글자 대신)
  - 바다가 일렁이고, 해변에 파도가 밀려와 부서지고, 물결이 반짝이고, 갈매기가 날고 벚꽃잎이 살랑살랑 흩날려요 (`assets/lobby_water.png` = 물 영역)
  - 간판 4개를 누르면 들어가요: 🛡️ 안전체험관 · 🎵 동아리실 · 🌴 정글 모험 · 🏪 체험마을 (건물을 눌러도 돼요 · 키보드 1~4)
  - 위: 탐험가 얼굴(누르면 바꾸기)·Lv·XP · 강릉분원 완성 n/11(누르면 도감) · 지금 내 상태 ⚡활력 · ❤️다음 판 생명 · 🪙코인 · 🎒가방 (값이 바뀌면 톡 튀고, 누르면 관련 장소로)
  - 주인공이 마을을 걸어 다녀요: 땅을 누르면 그곳으로, 간판·건물을 누르면 걸어가서 들어가요 (조이스틱·방향키로 직접 이동, 문 앞에서 스페이스)
  - 왼쪽 아래 원숭이 마스코트가 오늘 할 일을 알려줘요 (누르면 다음 말 + 읽어주기)
  - 오른쪽 아래 오늘의 탐험 4개 (하나마다 🪙50, 모두 하면 🎁 선물) · 아래 버튼: 지도(마을 안내) · 가방 · 옷장 · 설정
  - 메뉴 화면 오른쪽 위 빨간 ✕(또는 ESC)로 언제든 닫을 수 있어요
- 🌴 정글 점프: 원래 게임 (게임 중에는 다른 활동이 끼어들지 않아요)
- ☕ 바리스타 체험실: 정글에서 모은 과일을 많이 써서 음료를 만들어 마시면 ⚡활력이 올라요 (최대 20)
  - 활력 1마다 글라이딩 시간 +5%, 물약 효과 시간 +2%, 점프 조금 더 높이
- 🍳 요리 체험실: 🧮 과일 값 계산하기(코인 세기)도 있어요. 손님 주문을 보고 과일과 재료(🥚 알 · 🍯 꿀 · 🥥 코코넛 · 🌾 밀)로 요리해 주면 아이템을 받아요
  - 아이템은 정글 점프 중 🎒 가방 버튼(키보드 B)으로 써요: 생명 하트, 거인·자석·체공·빛·요정 물약, 황금 파워
- 🦺 안전체험관: 어린 학생 눈높이의 학습 (그림 크게, 소리로 읽어주기, 틀려도 괜찮아요 응원)
  - ✏️ 과일 이름 쓰기 · 🍎 과일 짝꿍 찾기 · 🚦 안전 짝꿍 찾기 (23가지: 신호등, 소화기, 지진, 엘리베이터, 모르는 사람, 버스, 교통카드 등)
  - 🤔 이럴 땐 어떻게?: 그림 상황을 보고 알맞은 행동 고르기 (12가지 상황)
  - 짝을 맞추면 안전 약속을 읽어주고, 배운 안전 약속 카드가 모여요 · 끝내면 코인 보상
  - 별 3개(고득점)를 받으면 다음 정글 점프 한 판에서만 생명 +1 (최대 +3까지 모아둘 수 있고, 한 판이 시작되면 사라져요 · 2인 대결 제외)
- 🎮 e스포츠체험실: **과일팡** — 같은 과일 3개 이상을 가로·세로로 맞추면 팡!
  - 모드: ⏱️ 60초 도전 · 🗺️ 스테이지(강릉 명소 20단계: 경포대·안목 커피거리·오죽헌·정동진) · 📅 오늘의 과일팡(모두 같은 판) · 🌿 느긋한 모드(시간 제한 없음)
  - 특수 과일: 4개 한 줄 → 🚀 줄무늬(한 줄), ㄱ·ㅗ 모양 → 💥 폭탄(주변), 5개 한 줄 → 🌈 무지개(같은 과일 모두) · 특수끼리 바꾸면 더 큰 폭발
  - 스테이지 목표: 과일 모으기 · 🧊 얼음 깨기 · 🪨 돌 깨기 · 🌱 씨앗 바닥까지 내리기 (남은 횟수로 별 1~3개)

  - 파트너 스킬(게이지가 차면 누르기): 🐦 새 · 🧚 요정 · 🦉 부엉이 · 🧒 탐험가 · 요리체험실 손님의 과일팡 주문 · 이번 주 우리 반 순위
  - 선택: 🔍 큰 판(6×6) · 🔷 모양으로 구분(과일마다 다른 테두리)

  - 🎧 내 음악: 직접 만든 음악 파일(mp3·m4a·wav)을 올리면 박자를 찾아 세 난이도 노트를 자동으로 만들어요 (기기에 20곡까지 저장, 정글 배경음악으로도 등록 가능)
