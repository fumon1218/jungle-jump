# 🌴 정글 점프 탐험대

나뭇가지를 밟고 뛰어다니며 정글 열매를 모으고, 보물상자 속 빛나는 글자를 모아
**'강원특수교육원 강릉분원'**을 완성하는 횡스크롤 게임입니다.
설치 없이 브라우저에서 바로 실행되며 PC와 모바일(터치) 모두 지원합니다.

## 그림
- 기본 탐험가 캐릭터(달리기·점프 모습)와 스테이지 1~4 배경 그림이 index.html 안에 내장되어 있어요
- 발판은 배경 그림에 맞춰 이끼 낀 돌판, 떠 있는 돌섬, 통나무(밟으면 부서짐)로 그려져요

## 게임 방법
- 이동: ← → 또는 A / D
- 점프: 스페이스, ↑ 또는 W (공중에서 한 번 더 누르면 2단 점프, 짧게 누르면 낮은 점프)
- 글라이딩: 떨어질 때 점프를 계속 누르고 있기
- 슬라이딩: ↓ 또는 S (모바일은 오른쪽 아래 ▼ 버튼)
- 일시정지: P 또는 Esc
- 모바일·태블릿: 왼쪽 아래 ◀ ▶ 버튼으로 이동 (손가락을 떼지 않고 미끄러져도 방향 전환)
- 모바일·태블릿: 화면 아무 곳이나 탭하면 점프, 두 번 탭하면 2단 점프, 길게 누르면 더 높이
- 가로 화면을 권장하며, 홈 화면에 추가하면 앱처럼 전체 화면으로 실행돼요

## 규칙
- 보물상자를 열면 '강 원 특 수 교 육 원 강 릉 분 원' 중 한 글자가 랜덤으로 나와요 (가끔은 물약)
- 11글자를 모두 모아 '강원특수교육원 강릉분원'이 완성되면 엔딩, 생명이 다 떨어지면 종료
- 생명 5개로 시작 (최대 8개)
- 생명 얻기: 하트, 보물상자의 생명 상자, 한 판에 코인 100개마다, 고릴라 추격전 도망 성공, 비밀 동굴과 보스전의 하트
- 열매: 바나나 10, 체리 15, 망고 20, 용과 40 — 끊기지 않게 먹으면 콤보 (5콤보 ×2, 10콤보 ×3)
- 피해야 할 것: 해골 독열매, 매달린 독거미, 늪 물, 금 간 가지(밟으면 곧 부서짐)
- 독거미는 위에서 밟으면 물리칠 수 있어요
- 날아오는 앵무새에 닿으면 몇 초간 타고 날아가요 (점프하면 내림)
- 화면 오른쪽 끝 화살표가 다음 보물상자 방향을 알려줘요

## 탐험가 기술 · 수집
- 가시 덩굴은 슬라이딩으로만 지나갈 수 있어요
- 황금 열매: 10초 동안 커지고, 장애물을 부수고, 열매와 코인을 끌어당겨요
- 코인을 모아 옷장에서 캐릭터(탐험가·원숭이·아기 호랑이·잠수복·우주복·황금 탐험가·내 그림), 점프 잔상(별빛·발자국·하트·나뭇잎·무지개), 파트너(파랑새·꼬마 요정·아기 부엉이)를 고를 수 있어요
- 파트너는 보너스 코인 위치를 알려주고, 물에 빠지기 직전 한 번 구해줘요

## 스릴 · 장치
- 고릴라 추격전: 900m부터 1300m마다 분노한 고릴라가 쫓아와요. 화면이 저절로 흘러가니 250m 동안 뒤처지지 말고 달려요 (따돌리면 코인 +20)
- 점프 버섯: 밟으면 일반 점프의 약 3배 높이로 튕겨 올라 하늘의 코인을 모을 수 있어요
- 줄타기 덩굴: 매달린 뒤 앞으로 크게 흔들릴 때 점프하면 대각선 위로 멀리 날아가요
- 도레미 코인: 코인을 연달아 먹으면 도-레-미-파-솔-라-시-도로 음이 올라가고, 8개째마다 폭죽과 보너스 점수
- 비밀 동굴 포탈: 드물게 나오는 무지개 포탈에 들어가면 10초 동안 코인과 열매가 쏟아지는 보너스 동굴로 가요
- 소나기: 비가 오면 발판이 미끄러워 잘 멈추지 않아요 (화산 지대 제외)

## 물약 (10초)
체공(천천히 떨어짐) · 빛(몸이 빛나 어둠을 밝힘) · 요정(요정이 따라다님) · 자석(열매가 끌려옴) · 거인(커지고 한 번 막아줌) · 느림보(느려짐) · 혼란(좌우 반대)

## 스테이지
- 500m마다 스테이지가 바뀌어요 (4 다음엔 다시 1)
  - 스테이지 1 · 폭포 정글: 이끼 낀 돌 발판, 청록빛 강
  - 스테이지 2 · 나무 위 마을: 나무 판자 발판, 떨어지는 나뭇잎
  - 스테이지 3 · 고대 유적: 무늬가 새겨진 돌 발판, 안개와 빛줄기
  - 스테이지 4 · 화산 지대: 달아오른 현무암 발판, 물 대신 용암, 불티
- 달릴수록 낮 → 노을 → 밤 → 새벽 (밤에는 반딧불이가 나와요)

## 마지막 관문
- 글자 11개를 모두 모으면 화산 결투장에서 고릴라 대장과 대결해요
- 돌진(! 표시), 점프 충격파, 떨어지는 바위를 피하면서 머리를 3번 밟으면 승리 → 엔딩

## 더 즐기기
- 연습하기: 처음 시작하면 걷기·점프·2단 점프·글라이딩·슬라이딩·보물상자를 차례로 익히는 연습 구간부터 시작해요
- 이어하기: 게임 도중 나가도 마지막 위치에서 다시 시작할 수 있어요
- 오늘의 도전: 날짜마다 모두 같은 맵, 매일 바뀌는 목표 (성공하면 코인 +50)
- 2인 대결: 한 기기로 두 사람이 같은 맵을 번갈아 달려 점수를 겨뤄요
- 순위표: 이 기기에서 플레이한 사람들끼리 점수 순위 (게임이 끝나면 이름을 올려요)
- 기록 카드: 결과 화면에서 캐릭터·모은 글자·점수가 담긴 이미지를 저장하거나 공유해요
- 업적 배지 12종: 도감에서 확인해요

## 설정
- 배경음악·효과음 크기, 화면 흔들림 끄기, 번쩍이는 효과 끄기, 조작 버튼 크기, 가벼운 모드(자동/켜기/끄기)
- 플레이 통계: 생명을 잃은 이유와 스테이지별 횟수를 보여줘요 (난이도 조정할 때 참고)

## 난이도 · 기록
- 쉬움: 물에 빠져도 생명이 줄지 않고, 거미가 느리고, 가지 사이가 가까워요
- 도감: 모은 글자, 완성 횟수, 가장 빠른 완성 시간, 칭호(강릉분원 탐험가 → 정글 베테랑 → 전설의 탐험대장)
- 기록은 그 기기의 브라우저에 저장돼요

## 나만의 캐릭터 · 배경음악
- 시작 화면의 **꾸미기** 버튼에서 주인공 이미지, 점프 모습(선택), 배경음악을 불러올 수 있어요
- 그림 배경은 자동으로 지워지고 여백도 잘려요 (옵션으로 끌 수 있음)
- 불러온 파일은 그 기기의 브라우저에 저장돼요
- 모든 방문자에게 보이게 하려면 `player.png`, `player-jump.png`, `bgm.mp3`를 index.html 옆에 올리세요

## 내가 그린 아이템
- 꾸미기 화면의 '아이템 그림'에서 PNG를 불러오면 바로 게임에 적용돼요 (이 기기에 저장)
- 모든 방문자에게 보이게 하려면 저장소에 `items` 폴더를 만들고 아래 이름으로 올리세요

- 배경이 투명한 정사각형 PNG(128×128 정도)를 추천해요

## 새 아이템 만들기
- 시작 화면의 '내 아이템'에서 직접 그린 PNG로 완전히 새로운 아이템을 만들 수 있어요 (최대 20개)
- 능력 7가지: 점수 열매, 코인 주머니, 생명, 마법 효과(물약 효과 선택), 함정, 움직이는 적(밟으면 물리침), 점프대
- 나오는 빈도(드물게·보통·자주), 크기, 놓는 곳(가지 위·높은 공중)을 정할 수 있어요
- '시험' 버튼을 누르면 그 아이템이 많이 나오는 판으로 바로 확인해요
- 내보내기로 받은 `custom.json`을 저장소 `items/custom.json`으로 올리면 모든 방문자에게 나와요 (다른 기기로 옮길 땐 가져오기)

## GitHub Pages로 배포
1. 새 저장소를 만들고 `index.html`, `README.md`를 업로드
2. Settings → Pages → Branch를 `main` / `(root)`로 저장
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 에서 플레이
